# My Financial Dashboard (mf-csv-dashboard)

家計簿サービスからエクスポートしたCSV（家計簿データ `/cf` と資産推移
`/bs/history`。Money Forward ME形式に対応）をローカルで可視化するダッシュボード。
完全ローカル動作。

## 入力CSVの形式

2種類のCSVを読み込む。どちらも Shift-JIS (CP932) のままでよい。

### 1. 家計簿データ（月次、複数ファイル）

`private-csv/YYYY-MM.csv`（例: `private-csv/2025-08.csv`）という名前で、
月ごとに1ファイル配置する。ヘッダーは以下の10列:

```
計算対象,日付,内容,金額（円）,保有金融機関,大項目,中項目,メモ,振替,ID
```

### 2. 資産推移データ（1ファイル）

`private-csv/資産推移月次.csv` という名前で1ファイル配置する。
1列目は `日付`、2列目以降は保有している資産種別ごとの残高列
（例: `合計（円）`, `預金・現金（円）`, `投資信託（円）`, `ポイント（円）` など。
実際に保有している資産の種類によって列は変わる。列名は動的に読み取るので
増減しても対応可能）。

いずれもMoney Forward MEのWeb版からダウンロードできるCSV
（家計簿データは `/cf` 画面下部、資産推移は `/bs/history` 画面）を想定しているが、
同じ列構成のCSVであれば他のサービス由来でも読み込める。

## 使い方

1. 上記の形式でCSVを `private-csv/` に配置する。
2. `app/` で依存関係をインストールして起動:
   ```
   cd app
   npm install
   npm run dev
   ```
   `npm run dev` / `npm run build` は自動的に `private-csv/` を読み込んで
   リポジトリルートの `private-data/`（gitignore対象、パーミッション600）に
   `transactions.json` 等を再生成してから起動・ビルドする。
   `app/` 配下にはデータファイルを一切置かないので、`app/` を丸ごと
   `git add` してもセンシティブなデータが混ざらない。

## 非経常項目（立替・臨時収入・特別な支出）の除外

判定ルールは2つに分かれている:

- `classify-rules.default.json`（リポジトリルート、コミット対象）:
  個人名などを含まない公開用デフォルトルール。
- `private-data/classify-rules.local.json`（`private-data/`配下、gitignore対象）:
  個人名など公開したくないカテゴリ名を使うルールをここに追加する。
  テンプレートは `classify-rules.local.example.json` を参照。

ビルド時にこの2つがマージされて `private-data/classify-rules.json` になる。
移動平均・年次集計の「非経常項目を除外」チェックボックスはこの結果を使う。
編集後は保存するだけで dev サーバーに反映される。

## ビュー

- 月次移動平均: 収入・支出・収支の月次実測値と3/5/12ヶ月移動平均
- 年次資金推移: 年ごとの収入・支出・収支（棒＋折れ線）
- 資産推移: `資産推移月次.csv` からの内訳付き実残高トレンド
